Лицензия / License: [LICENSE](LICENSE) · подлинность сборки: [INTEGRITY.md](INTEGRITY.md)

## Возможности
- Чат с ИИ: режимы «Агент» и «Вопрос», подтверждения действий, @файл, правка кода Ctrl+K.
- Офлайн-модели через Ollama и облачные провайдеры (Groq, Gemini, DeepSeek, OpenAI и другие), несколько ключей с автопереключением.
- Редактор: подсветка, автодополнение, поиск в файле (Ctrl+F), переход к строке (Ctrl+G), дублирование/перенос строк.
- Замена по всему проекту с предпросмотром, история правок с откатом.
- Проект в ZIP: скачать и загрузить; шаблоны файлов.
- Терминал, запуск F5 и отладка Shift+F5, голосовой ввод (офлайн), палитра команд Ctrl+Shift+P.
- Проверка окружения и обновлений, уведомление о готовом ответе, 7 тем и тонкая настройка оформления.
