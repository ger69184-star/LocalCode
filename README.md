# LocalCode

Локальный редактор кода с ассистентом: работает на своём компьютере (Ollama)
или через облачную модель. Без внешних библиотек, сервер доступен только
с этого компьютера и требует одноразовый токен.

Документация: [docs/README.txt](docs/README.txt) · [справочник](docs/LocalCode-spravochnik.txt) ·
[безопасность](docs/SECURITY.md) · [подлинность сборки](docs/INTEGRITY.md) ·
[изменения](docs/CHANGELOG.md) · лицензия: [LICENSE](LICENSE).

## Возможности
- Чат: режимы «Агент» и «Вопрос», подтверждение действий, «Разрешить всегда», @файл, правка Ctrl+K.
- **Полный доступ к компьютеру**: файлы в любом месте (кроме секретов), команды в любой папке,
  инструмент `system` — сведения о ПК, диски, процессы, окна, снимок экрана, буфер обмена,
  громкость, блокировка, сон, выключение и перезагрузка с подтверждением.
- Редактор: поиск и замена (регистр, регулярные выражения), подсветка текущей строки,
  Alt+Z — перенос строк, Ctrl+/ — комментарий, Ctrl+D — дублировать, Alt+↑/↓ — перенести,
  форматирование JSON, Ctrl+Shift+S — сохранить все вкладки.
- Офлайн-модели через Ollama и облачные провайдеры (Groq, Gemini, DeepSeek, OpenAI и другие).
- Замена по всему проекту, история правок с откатом, проект в ZIP, шаблоны файлов.
- Терминал, запуск F5, отладка Shift+F5, голосовой ввод, палитра Ctrl+Shift+P, 7 тем.
