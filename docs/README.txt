LocalCode 1.0.0 — локальный редактор кода с ассистентом
======================================================

КОРОТКО
-------
LocalCode — программа для Windows, macOS и Linux: редактор кода и ассистент,
который работает на вашем компьютере или через облачную модель. Сервер
слушает только этот компьютер (127.0.0.1) и требует одноразовый токен.
Node.js 18+ обязателен, сторонних библиотек нет.

УСТАНОВКА (один раз)
--------------------
  1. Распакуйте архив в постоянную папку, например C:\LocalCode.
  2. Запустите install.bat — он поставит Node.js, Ollama и подходящую модель.
  3. Запустите Create-Shortcut.bat — появится ярлык на рабочем столе.

Запуск: ярлык «LocalCode» (или LocalCode.vbs). Закроете окно — программа
остановится. Повторный запуск просто открывает уже работающее окно.
Обновление: распакуйте новый архив поверх старой папки; install.bat не нужен.

КАК УСТРОЕНЫ ФАЙЛЫ (для новичка)
--------------------------------
В корне лежит только то, что нужно запускать:

  install.bat / install.sh      установка (Windows / macOS, Linux)
  Create-Shortcut.bat           ярлык на рабочем столе (Windows)
  LocalCode.vbs                 запуск без окна консоли (Windows)
  LocalCode.bat                 запуск с консолью — видно ошибки
  README.md, LICENSE            описание и лицензия

Файлов программы в корне нет: всё, что относится к коду, лежит в app/.

Папки:

  app\                          сама программа
    server.js                   сервер: файлы, команды, модели, system
    public\                     интерфейс: index.html, app.js, style.css,
                                i18n.js, highlight.js
    hw.js, integrity.js         проверка компьютера и подлинности сборки
    models.json                 каталог моделей Ollama
  installer\install.js          установка и создание ярлыков
  docs\                         документация
    README.txt                  этот файл
    LocalCode-spravochnik.txt   подробный справочник
    SECURITY.md                 что защищено и какие есть ограничения
    INTEGRITY.md                подлинность сборки
    CHANGELOG.md                что нового
  tests\                        тесты: npm test
  tools\integrity-cli.js        проверка подписи из командной строки

ЖУРНАЛ
------
localcode.log создаётся рядом с программой при запуске. Если что-то не
работает, запустите LocalCode.bat — в консоли будет понятная ошибка.
Диагностика: http://localhost:3000/api/health (порт указан в журнале).

ЧТО УМЕЕТ
---------
  - Чат: режимы «Агент» и «Вопрос», @файл, правка кода Ctrl+K, подтверждение
    действий кнопкой «Выполнить», «Разрешить всегда» для повторяющихся шагов.
  - Полный доступ к компьютеру: файлы в любом месте (кроме секретов), запуск
    команд в любой папке, управление системой через инструмент system:
    сведения о ПК, диски, процессы, окна, снимок экрана, буфер обмена,
    громкость, блокировка, сон, выключение и перезагрузка (с подтверждением).
    Режим включается и выключается в Настройки → Общие → Безопасность.
  - Редактор: подсветка, дополнение, поиск и замена с учётом регистра и
    регулярных выражений, переход к строке, подсветка текущей строки,
    перенос строк (Alt+Z), комментарии (Ctrl+/), дублирование (Ctrl+D),
    перемещение строк (Alt+↑/↓), форматирование JSON, сохранение всех
    вкладок (Ctrl+Shift+S), закрытие вкладки (Ctrl+W).
  - Офлайн-модели через Ollama и облачные провайдеры (Groq, Gemini, DeepSeek,
    OpenAI и другие), несколько ключей с автопереключением.
  - Замена по всему проекту, история правок с откатом, проект в ZIP.
  - Терминал, запуск F5 и отладка Shift+F5, голосовой ввод, палитра Ctrl+Shift+P.
  - 7 тем, свои цвета и шрифты, спокойное оформление без «неоновых» градиентов.

БЕЗОПАСНОСТЬ (кратко; подробно — docs\SECURITY.md)
--------------------------------------------------
  - Сервер доступен только с этого компьютера и требует одноразовый токен.
  - Опасные действия (команды, правка и удаление файлов, system) подтверждаются.
    Сведения о ПК, диски, процессы и окна — без подтверждения, они только читают.
  - В полном доступе файлы разрешены везде, но .env, приватные ключи и
    .git/config по-прежнему закрыты; удалять корень диска и системные
    каталоги нельзя, даже с подтверждением.
  - Выключение и перезагрузка требуют отдельного подтверждения (confirm),
    завершить процесс с PID 1–4 или сам сервер нельзя.
  - Не делайте проброс порта наружу и не отключайте подтверждения без нужды.

ЛИЦЕНЗИЯ
--------
Программа бесплатная: ключей активации, подписки и пробного периода нет.
Настройки -> О программе показывают, совпадают ли файлы с официальной
подписанной сборкой. Продавать программу и выдавать изменённые сборки за
официальные запрещено (LICENSE).

ENGLISH (short)
---------------
Install once: unpack, run install.bat, then Create-Shortcut.bat. Start with the
desktop shortcut (LocalCode.vbs); closing the window stops the program.
Update: unpack the new archive over the old folder. Layout: app/ (server and
public UI), installer/, docs/, tests/, tools/. Tests: npm test (Node 18+).
Full access to files and system tools (system: info, disks, processes, windows,
screenshot, clipboard, volume, lock, sleep, shutdown) is on by default and can
be turned off in Settings -> Security. Dangerous actions still ask for approval.
