# Что нового в LocalCode

## 1.0.0
- Полный доступ к компьютеру: файлы в любом месте (файлы с секретами по-прежнему
  закрыты, удаление системных каталогов запрещено), команды в любой папке (`cwd` у run_command), режим включается в
  Настройки → Общие → Безопасность и показывается бейджем в шапке.
- Инструмент `system`: сведения о ПК, диски, процессы, окна, снимок экрана, буфер обмена,
  громкость, блокировка, сон, выключение/перезагрузка (только с `confirm:true`), завершение
  процесса. Windows, macOS и Linux; понятные ошибки, если утилиты нет.
- Исправлено: действия агента после разрешения действительно выполняются; добавлено
  «Разрешить всегда» и автоматический переход на текстовый агент, если модель не умеет
  вызывать инструменты.
- Новая раскладка: программа в `app/`, установщик в `installer/`, документация в `docs/`,
  в корне только то, что запускают. Обновлены батники, ярлыки, тесты и документация.
- Оформление переработано: спокойные нейтральные панели, один синий акцент, без градиентов,
  свечения и «ИИ-фиолетового»; плоские сообщения чата, обычные подписи кнопок.
- Первый экран объясняет три шага новичку; F1 — шпаргалка по клавишам.
- Редактор: панель частых действий, поиск и замена в файле с регистром и регулярными
  выражениями, подсветка текущей строки, перенос строк (Alt+Z, Ctrl+H),
  Ctrl+Shift+S — сохранить все вкладки, Ctrl+W — закрыть вкладку, статус с EOL и выделением.
- Повторный аудит: исправлено преждевременное обращение к `applyConf`, рассинхрон поля
  `full` в `/api/access` и потеря защиты секретов в полном доступе; тесты 47/47.

## 0.9.0
- Замена по всему проекту: предпросмотр числа совпадений, подтверждение, отчёт по файлам, лимиты
  (регулярные выражения с пустым совпадением отклоняются, результат ограничен 5 МБ).
- История правок: снимок файла перед каждым сохранением, просмотр списка и откат в один клик.
- Проект в ZIP: скачивание и загрузка обратно. Свой распаковщик без внешних программ проверяет пути
  (защита от «zip-slip»), секреты в архив не попадают.
- «О программе»: проверка окружения (версия, Node.js, память, диск, Git, Ollama) и проверка обновлений.
- Шаблоны файлов: сохранить текущий файл как шаблон и вставить его в новый файл (локально).
- Редактор: поиск внутри файла (Ctrl+F), переход к строке (Ctrl+G), дублирование строки (Ctrl+D),
  удаление строки (Ctrl+Shift+K), перенос строк (Alt+↑/↓), сортировка выделенных строк,
  удаление пробелов в конце строк, форматирование JSON.
- Уведомление в системе, когда долгий ответ готов (по желанию).
- Повторный запуск открывает уже работающее окно, а не поднимает второй сервер (`session.json`, `0600`).
- Производительность: кэш списка файлов и статуса Git на сервере, отложенная запись вкладок,
  кэш статики с ETag/304 и сжатием, статус-бар без лишних проходов по тексту.
- Аудит и исправления: закрыт обход запрета локальных адресов через IPv4-в-IPv6 и NAT64,
  импорт ZIP до 25 МБ больше не упирается в лимит тела запроса, проверяются границы данных в ZIP,
  настройки из localStorage нормализуются (битые настройки не ломают окно), список истории
  ограничен по объёму чтения, длинные выделения и @-файлы обрезаются до контекста модели,
  поиск в файле не сдвигает позиции на Unicode, переключение вкладок не перезагружает дерево,
  исправлена подсказка с путём проекта и потеря несохранённых правок из истории.
